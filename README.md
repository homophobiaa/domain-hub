# Domain Hub

A premium, frontend-only domain parking hub for my unused and reserved domains.

All domains I own but don’t actively use redirect here.

## ✨ Features

- Animated landing page with modern UI
- Domain-aware (detects current hostname)
- Highlights the active domain
- Clean card-based layout for all domains
- Lightweight and fast (static build)

## 🌐 Domains

- getflowhub.app
- getflowhub.xyz
- getflowhub.cloud

## 🛠 Tech Stack

- React + TypeScript
- Vite
- CSS (custom animations)

## 🚀 Deployment

Hosted on Vercel as a static site.

All domains point to the same deployment.

## 📌 Purpose

This project acts as a central hub for:
- Reserved domains
- Experimental domains
- Future project placeholders

Instead of leaving domains unused or blank, they redirect to a clean, branded page.
